# Verses & Whispers

A minimalist personal poetry portfolio and digital journal with a paper-like design. Built with a clean aesthetic reminiscent of a physical notebook, smooth typography, and a multi-page structure.

## Aesthetics & Design
- **Color Palette:** Warm paper tones (background `#f4efe6`, cards `#fffcf7`, and soft brown accents).
- **Typography:** Google Fonts (`Caveat` for titles and `Playfair Display` for poems and body text).
- **Layout:** Responsive gallery on the homepage leading to dedicated, distraction-free reading pages for individual poems.

## Project Structure

```text
├── poetry_journal.html         # Main journal homepage (gallery of cards)
├── how_to_kill_time.html       # Dedicated page for "How to kill time?"
├── the_love.html               # Dedicated page for "Love"
├── whispers_of_orpheus.html    # Dedicated page for "Whispers of Orpheus"
└── poetry.html                 # Dedicated page for "Poetry"

```text
